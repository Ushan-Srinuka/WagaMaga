# Plus Jakarta Sans font asset

Retrieved 17 November 2026 for the homepage, then extended to the other existing screens at the user's request. The Latin upright variable WOFF2 is self-hosted; users' browsers make no Google Fonts request. Weight range: 400-800. Shared font registration/tokens are in src/theme.css and used by home, authentication, account, administrator, shared-state and developer connection screens. The selected Latin subset serves the current English UI; revisit glyph coverage before introducing other languages.
